## 当前结论

- `_c snapshot_8` 已建立手部局部能力：InterHand-test 全量 **OSX 19.58mm → 16.82mm**，HInt hand-crop held-out **OSX `[wa]` 0.487 → 0.480**。
- `face_ubody_e snapshot_4` 冻手训脸，HInt 与 `_c` 完全一致；脸只恢复到 EHF Face 约 6.20mm，未超过 OSX 约 6.09mm。
- Stage 3 `joint_polish_f` 已收口，终点 `snapshot_2`：InterHand **16.76mm**，UBody natural-hand `[wa]` **0.250→0.229**，HInt 仍约 **0.480**，EHF Face 6.25。Stage 3 的真实贡献是修 UBody full-body natural-hand 退化，不是提升 HInt。
- `coco_pilot` no-gate 稳定但只是轻微 polish：HInt 基本不动，InterHand 约 **16.67-16.69mm**，UBody `[wa]` 约 **0.227-0.228**。MSCOCO hard ROI gate 曾在约 1.3k iter 后导致 loss 整体飙高，暂不采用。
- 当前手部主问题：**HInt hand-crop 已小幅赢 OSX，但 UBody full-body natural-hand 仍未追平 OSX 0.219**。后续不要只盯 HInt。

## 当前关键指标

| 模型 | InterHand PA | HInt `[wa]` NME | UBody `[wa]` NME | 结论 |
|---|---:|---:|---:|---|
| OSX normal | 19.58 | 0.487 | 0.219 | 原始 baseline |
| `_c snapshot_8` | 16.82 | 0.480 | 0.250（由 `face_ubody_e` 冻手等价） | 局部手能力成立，UBody 退化 |
| `joint_polish_f snapshot_2` | 16.76 | 0.480 | 0.229 | Stage 3 终点，修复 UBody 但未追平 |
| `coco_pilot snapshot_1/itr3000` | 16.67-16.69 | 0.480-0.481 | 0.227-0.228 | 轻微 polish，HInt 无新增 |

## 下一步建议

1. 不再继续同配方 COCO pilot 长训；no-gate 结果可作为 polish checkpoint，但不是主突破。
2. 不要直接开启 `--mscoco_use_hand_roi_quality`；当前 hard gate 在 MSCOCO 上 pass 率低且已证实不稳。若再试，只能改 soft weighting 或低阈值短跑。
3. 若继续手部主线，优先小心版路线 C：解冻 `hand_roi_net`，与 hand decoder/regressor 小 LR 共适应；先不动 `box_net`，主判据看 UBody natural-hand，HInt/InterHand 只做 guardrail。
4. 身体 shape T1 是独立附带线：代码已实现，默认关闭；目标是 `body_regressor.shape_out` + `cam_out` 修 betas mean-reversion，详见 `experiment_log.md` 2026-06-25。

## 常用评估命令

HInt：

```bash
cd /workspace/myosx/main
python test.py --gpu 0 --testset HInt --exp_name output/eval_hint \
  --decoder_setting pytorch --encoder_setting osx_l \
  --pretrained_model_path ../pretrained_models/osx_l.pth.tar \
  --continue_train_path ../output/joint_polish_f/model_dump/snapshot_2.pth.tar \
  --hint_root /workspace/HInt_annotation_partial \
  --hint_split test --hint_sources epick,newdays
```

UBody natural-hand：

```bash
cd /workspace/myosx/main

python test.py --gpu 0 --testset UBody --exp_name output/eval_joint_polish_f \
```
