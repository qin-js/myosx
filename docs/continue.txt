## 当前结论（2026-06-27 重大更新）

- **编码器移植 bug 已修复**：`StandardViT`(pytorch 路径)的 `PatchEmbed` 卷积 padding 之前是 0，OSX MMCV ViT 是 2，导致 patch 特征系统性错（`img_feat` 相对 OSX 偏 24%，但形状相同所以一直隐形）。修复后(`common/nets/vit.py`，padding=2 + LayerNorm eps 1e-6)，pytorch 编码器与 OSX **逐比特一致**。验证工具 `tool/analysis/encoder_compare.py`、`crosspath_compare.py`。
- **手头对修复完全鲁棒、无需重训**：`snapshot_2`(旧编码器训出)直接在修复编码器上评测，InterHand PA 16.76→**16.78**、UBody/HInt `[wa]` 纹丝不动。snap2@修复是可用工作基线。
- **编码器修复净赚**：UBody `[abs]` 0.324→**0.316**、EHF Face 6.25→**6.15**，免费向 OSX 收敛（之前的"自然手/[abs]退化"有一块就是这个 bug）。
- **唯一真问题被干净隔离**：UBody `[wa]` 0.229 vs OSX 0.219 的 **0.010**，在 body 与 OSX 逐比特一致后仍在 → 100% 是手头自然图相对手指 articulation。配对 bootstrap CI `[-0.0117,-0.0087]`、显著。
- **InterHand −14% 的 caveat**：OSX 原始训练集**不含 InterHand26M**，−14% 本质是"我们微调 vs OSX 零样本"，论文需补公平基线或改用 held-out(HInt) 当 headline。

## 下一步建议

**decoder 坐标精修结构线已判定「不打闸」（7-03 L728 负结果收口）。InterHand PA 的杠杆不在 2D 坐标机制——PA 是 Procrustes 对齐、只测手内 3D articulation，由 `hand_regressor` 的 3D pose 输出决定，与我们一直在优化的 2D 坐标精修/aux 2D loss 近正交（held-out HInt 2D 我们赢、in-domain InterHand PA 追不上，正是同一事实的两面）。主线换挡:停止再投 decoder 结构变体去追 PA。**

> **（2026-07-03 换挡）目标定位不变（相对 stock OSX 全绿、非顶会可发）,但方法 claim 的落点从「decoder 结构优越」改为「① 我们赢的 2D 轴（held-out HInt）+ ② 高效冻结骨干 recipe + ③ decoder 结构消融（含 L728/gate 负结论）作分析」。追 InterHand PA 只剩两个便宜、对靶的杠杆值得一试,试完即封口。**

**A. 若还想动 InterHand PA 16.78→16.3（只剩这两个对靶杠杆,各一次即封口）:**
1. **杀/降 aux 2D coord loss**（`hand_aux_coord_loss_weight` 1.0→0.1 或 0）:直接验证假设「aux 2D 监督在和 3D pose 抢梯度/容量」。gate aux 0.36 好但 PA 卡 16.80、L728 把更好的 2D 喂进去 PA 反退——都指向 2D 精度 ⊥（甚至反相关于）3D PA。最便宜的诊断,先做。
2. **rotmat pose loss**（`use_hand_rotmat_pose_loss`,已实现未试）:直接在旋转矩阵空间监督手姿——**这才是 PA 真正 care 的目标**,仅 InterHand/BEDLAM 可靠 hand pose GT 处 fire。L728 证 2D 坐标杠杆无效后,pose 空间监督是逻辑上唯一对靶的下一步。低风险。
   → 若 1+2 都不动 PA,则 InterHand PA 认「in-domain 追平/略负」,不再纠缠。

**B. 无论 A 结果如何,论文故事锁在我们赢的轴（已决定的目标下沉,现在有 L728 佐证更硬）:**
3. **headline = held-out HInt**（两模型都没训过、我们 0.487→0.480 赢;HInt 测 wrist-aligned 2D,正是我们 decoder 强的轴）;InterHand 降级为诚实 in-domain（fine-tune-vs-zero-shot caveat）。轨 B 公平基线 16.29 已跑出（OSX 略胜 0.49mm）——写成「各自最佳 init、同数据微调,in-domain 追平/略负,held-out 领先」。
4. **decoder 结构消融进 Table 4**:L728（refined coord→regressor = PA +0.25、`[wa]` 无变化）+ gate（迭代采样+aux 单独价值）作负/中性行,科学价值 = 「证明 2D 坐标精修与 whole-body 手 3D PA 正交」,是分析贡献不是失败。
5. **正交附带线**:UBody `[wa]` 走 T1 shape/cam（0.204 已反超 OSX,但需拆 shape/cam 消融压 `[abs]` 退化,见 7-02）;teacher distillation 锁 UBody parity。均独立于 decoder 线。
